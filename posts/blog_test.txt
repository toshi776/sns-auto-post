# はじめに

これは静的サイトジェネレーターを使用した自動投稿のテストです。

## システムの特徴

- **マークダウン対応**: 記事をマークダウンで記述
- **自動HTML生成**: Pythonスクリプトで自動変換
- **FTP自動アップロード**: サーバーへの自動デプロイ

## 技術スタック

```python
# 使用技術
- Python 3.10+
- Jinja2（テンプレートエンジン）
- Markdown（マークダウンパーサー）
- FTP（ファイル転送）
```

## まとめ

静的ブログへの自動投稿機能が正常に実装されました。
